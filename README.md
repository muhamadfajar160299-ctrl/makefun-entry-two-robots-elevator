One funny line of awkward small talk that one robot says to another while
they ride an elevator together — machine logic showing through forced
politeness, with the silence getting measurably worse.

## Run

```sh
python3 -S main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, otherwise to
`entry.txt` in the current directory.
